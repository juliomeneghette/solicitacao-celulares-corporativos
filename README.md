# 📱 Sistema de Solicitação de Celulares Corporativos

## 📖 Sobre o Projeto

Sistema desenvolvido para centralizar e controlar solicitações de celulares corporativos, incluindo aquisição, manutenção, substituição e acompanhamento das demandas.

O projeto surgiu da necessidade de otimizar o processo de gestão de dispositivos móveis dentro do ambiente corporativo.

---

## 🎯 Objetivo

Padronizar as solicitações de celulares corporativos, reduzir controles manuais e aumentar a rastreabilidade das informações.

---

## ⚙️ Funcionalidades

- Solicitação de novos aparelhos
- Solicitação de manutenção
- Registro de justificativas
- Acompanhamento das solicitações
- Interface intuitiva para usuários

---

## 🛠️ Tecnologias Utilizadas

- HTML
- CSS
- JavaScript

---

## 🚀 Próximas Melhorias

- Integração com banco de dados
- Painel administrativo
- Controle de status das solicitações
- Histórico de movimentações
